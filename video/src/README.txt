把 AI 生成的绿幕视频（mp4 / mov / webm / mkv）丢进这个文件夹，
然后双击工作区根目录的 make-webm.cmd（不带参数）。

可以在这里直接建分类子目录，成品会镜像到 assets/webm 的同一个子目录：

    video/src/吃吃喝喝/吃饺子.mp4   →   assets/webm/吃吃喝喝/吃饺子.webm
    video/src/节令/吃青团.mp4       →   assets/webm/节令/吃青团.webm
    video/src/平铺在根上.mp4        →   assets/webm/平铺在根上.webm

缺的目录会自动新建。assets/webm 里的目录只增不减，废弃的素材自己去删。

脚本会：
  1. 列出有几个视频（递归所有子目录）、几个已经有成品
  2. 只处理还没生成过的，已生成的跳过（源文件比成品新才会重做）
  3. 成品直接写进 assets/webm，不用手动复制
     宠物开着的话，下次点开右键菜单就能看到新动作，不用重启

文件名就是动画名。播什么完全由 assets/webm 的**目录名**决定，不用改配置：

    待机/ 转向/ 拖拽/ 走位/ 点击回应/   有特殊用途，放进对应目录就生效
    余额/ 碎碎念/                       特定剧情，不参与随机
    其它任何目录 / 根目录                → 随机小动作池（桌宠自己晃来晃去）

所以在 video/src 里建同名子目录，就等于在 assets/webm 里分好类。
想让新素材当「点一下的反应」，就放在 video/src/点击回应/ 下面。

（这个 README.txt 不会被当成视频处理。）
