## 投篮判定圈放大（hitRatio 0.9 → 1.3）

用户反馈「判定得分区域太小」。改动最小：只调配置，逻辑没动。

- `hit_ratio` 默认 0.9 → **1.3**，判定半径 50.8 → **73.3px**（筐口半径 56.4，判定圈比筐口大一圈）。
- `config._basketball()` 里 `hitRatio` 上界从 1.0 放宽到 **3.0** —— 之前夹到 1.0，写 1.3 会被静默截断成 1.0，
  这是「改了配置没效果」的坑。其余比例字段仍夹 (0,1]。
- `perfect_ratio` 保持 0.28（满分圈 14.2 → 20.5px，占比不变 → 难度曲线形状不变，只是整体放大）。
- 得分表（R=73.3）：0→10、20→10、30→8、40→7、50→5、60→3、70→2、73→1、80→0。
- 同步 `config.py` 两处 docstring、`config.jsonc` 注释、README 2.10 计分段 + 配置表；
  顺手订正 README 里「判定半径 = 筐口内径 × hitRatio」的笔误（应为 **半径 × hitRatio**）。
