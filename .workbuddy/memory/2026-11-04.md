## 多开时共用一个篮筐（每只宠物都能投）

需求：多只宠物只能有一个篮筐，且每只都能触发投篮计分。原来 `BasketGame` 绑死一只窗口
（`self.win`），只有它能投，从别的宠物点菜单会**先把这局收掉再开新的**。

- `BasketGame`：`self.win` → **`self.anchor`**（开局那只，只用来算筐放哪边 + 计分板字号），
  新增 `self.wins` 列表 + `attach(win)` / `detach(win)` / `_wire` / `_unwire`（lambda 绑死 `win`）。
  保留 `win` 只读 property 给旧调用点。
- 单份状态 `_shot/_scored/_best_d/_home/_home_timer` → **每只一份 `_Shot` dataclass**
  （live / scored / celebrate / best_d / home / timer），`self._shots[win]`。定时器**一只一个**，
  两只同时命中各回各的起点。所有回调签名改成先收 `win`。
- `main.toggle_game`：**全局开关** —— 只要 `self.game` 存在就结束整局（不管右键哪只），
  否则拿这只当 anchor 开局，并 `attach` 已开着的其它宠物。
- `main.close_pet`：改成 `game.detach(win)`，`wins` 空了才 `stop_game()`。
  `main.spawn`：游戏开着就自动 `attach`。菜单项 `playing` 判定去掉 `is win`。
- 分数仍是**整局共用**（一块计分板），不按宠物分账。

验证（离屏，两个脚本都在 `.workbuddy/_out_test/`，跑完即弃）：
- `multi_pet_basket.py`：可见 BasketWindow/ScorePanel 各 1 个；两只依次命中 10→20；
  两份 `_Shot` + 两个不同 timer 都在跑；`detach` 后剩下那只继续投到 30；`stop()` 全部解锁。
- `multi_pet_app.py`：PetApp 层 `spawn` 两只 → toggle 后 `wins==2`；从另一只 toggle = 结束；
  重开后 `close_pet` 一只 → 筐还在、`anchor` 自动转给剩下那只；游戏中 `spawn` 自动接入。
