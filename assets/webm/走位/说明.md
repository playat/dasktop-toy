# 走位动作

宠物自己挪动时用这里的素材，一次播完 = 走一段路。

**手感参数在 config.jsonc 的 `moves` 里**，不进这个文件夹：
  · `moves.default` —— 所有走位动作共用的默认值（行进距离、贴边距、首尾停顿秒数）
  · `moves.actions` —— 只写要覆盖的那几个键，用文件名当 name
    比如「原地左转奔跑」跑得远、尾巴停得久，单独给它 params 就行；没写的取 default

这里加素材不用改配置 —— 扔进来就算走位动作，参数自动用 default。
（从菜单点播这里的动作也会走完整一次走位，不会只原地踏步。）
